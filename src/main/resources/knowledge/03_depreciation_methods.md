# 折旧计算方法

## 折旧方法概述

系统支持三种折旧计算方法，通过策略模式和工厂模式实现动态切换。折旧方法存储于asset表的depreciation_method字段。

### STRAIGHT_LINE - 直线法

按月平均折旧，适用于价值均匀损耗的资产。

### DOUBLE_DECLINING_BALANCE - 双倍余额递减法

加速折旧，前期折旧额大后期小，适用于技术更新快的资产。

### WORK_UNIT - 工作量法

按实际工作量计算折旧，适用于生产设备等按工作量核算的资产。

## 直线法

### 计算公式

月折旧额 = 原值 / 使用月数

累计折旧 = 已计提月数 × 月折旧额

净值 = 原值 - 累计折旧

### 适用场景

- 资产价值均匀损耗
- 使用年限内各期使用强度相近
- 办公设备、家具等通用资产

### 计算逻辑

1. 获取资产原值和使用年限（月）
2. 计算月折旧额（原值除以使用月数）
3. 根据折旧期间计算期间折旧额
4. 更新累计折旧和净值
5. 净值不能为负数

### 示例

原值10000元，使用年限60个月（5年）

月折旧额 = 10000 / 60 = 166.67元

每月计提166.67元，5年后累计折旧10000元，净值为0

## 双倍余额递减法

### 计算公式

直线折旧率 = 1 / 使用年限（年）

双倍直线折旧率 = 2 × 直线折旧率

年折旧额 = 期初账面净值 × 双倍直线折旧率

最后两年改为直线法：（期初净值 - 残值）/ 2

### 适用场景

- 技术更新较快的资产
- 前期使用强度大后期减少的资产
- 电子设备、计算机等科技产品

### 计算逻辑

1. 计算双倍直线折旧率
2. 按递减余额计算折旧额
3. 最后两年改为平均分摊
4. 更新累计折旧和净值
5. 确保净值不低于残值

### 示例

原值10000元，使用年限5年

双倍折旧率 = 2 / 5 = 40%

第1年折旧 = 10000 × 40% = 4000元

第2年折旧 = 6000 × 40% = 2400元

第3年折旧 = 3600 × 40% = 1440元

第4-5年改为直线法：(2160 - 残值) / 2

## 工作量法

### 计算公式

单位工作量折旧额 = 原值 / 总工作量

期间折旧额 = 单位工作量折旧额 × 实际工作量

累计折旧 = 已完成工作量 × 单位工作量折旧额

净值 = 原值 - 累计折旧

### 适用场景

- 按工作量核算的生产设备
- 交通工具（按里程计算）
- 机器设备（按工时计算）

### 计算逻辑

1. 确定总工作量（资产预计可完成的总工作量）
2. 计算单位工作量折旧额
3. 根据实际完成工作量计算期间折旧额
4. 更新累计折旧和净值
5. 支持自定义实际工作量参数

### 示例

原值100000元，预计总工时10000小时

单位工时折旧额 = 100000 / 10000 = 10元/小时

本月实际工作200小时，折旧额 = 200 × 10 = 2000元

## 折旧工厂模式

系统采用工厂模式动态获取折旧计算器。

工厂类DepreciationCalculatorFactory维护折旧方法与计算器的映射关系。

调用时传入方法代码，工厂返回对应的计算器实例。

支持的方法代码：

- STRAIGHT_LINE → StraightLineDepreciationCalculator
- DOUBLE_DECLINING_BALANCE → DoubleDecliningBalanceDepreciationCalculator
- DOUBLE_DECLINING → DoubleDecliningBalanceDepreciationCalculator（别名）
- WORK_UNIT → WorkUnitDepreciationCalculator

未匹配的方法代码默认使用直线法计算器。

## 折旧记录

折旧计算结果存储于asset_depreciation表，关键字段：

- asset_id：资产ID
- asset_no：资产编号
- asset_name：资产名称
- depreciation_month：折旧月份
- depreciation_amount：折旧金额
- accumulated_depreciation：累计折旧
- current_net_value：当前净值
- original_value：原值
- depreciation_method：折旧方法
- useful_life：使用年限（月）
- used_months：已使用月数
- category_id：分类ID
- department_id：部门ID
- status：记录状态

## 折旧计算约束

### 资产状态约束

仅以下状态的资产可计提折旧：

- in_stock：在库
- using：使用中
- maintenance：维修中

已报废（scrapped）或已处置（disposed）的资产不再计提折旧。

### 原值约束

资产原值必须大于0才能进行折旧计算。

### 使用年限约束

资产使用年限必须大于0才能进行折旧计算。

### 使用年限检查

已使用月数达到或超过使用年限时，不再计提折旧。

### 累计折旧约束

累计折旧不能超过资产原值。

### 净值约束

资产净值不能为负数。

## 折旧计算流程

### 单资产折旧

1. 查询资产信息
2. 校验资产状态和字段
3. 查询累计折旧和已使用月数
4. 检查是否已达到使用年限
5. 根据折旧方法获取计算器
6. 执行折旧计算
7. 保存折旧记录
8. 更新资产净值

### 批量折旧

1. 遍历资产列表
2. 对每个资产执行单资产折旧流程
3. 记录成功和失败数量
4. 返回计算结果列表

### 重复计算处理

同一资产同一月份的折旧记录可重复计算，最新记录覆盖旧记录。

系统自动检查当月是否已有记录，有则更新，无则新增。

## 折旧配置

系统提供默认折旧配置：

- 默认折旧方法：STRAIGHT_LINE
- 默认使用年限：60个月（5年）
- 默认残值率：5%

配置存储于DepreciationConfig类，可通过配置文件调整。

## 折旧报表

系统提供多种折旧报表：

- 资产折旧记录查询（按资产ID）
- 折旧记录查询（按日期范围）
- 折旧记录查询（按分类）
- 折旧记录查询（按部门）
- 折旧汇总报表

报表数据来源于asset_depreciation表，支持多维度筛选。
